# План релиза SmartCRM v2.10

**Окно релиза:** согласовать после успешного CI и двух учебных спринтов. **Ответственный:** владелец репозитория. **Среда:** локальная Django + SQLite, учебная версия.

## Checklist
- [ ] Подтвердить объём изменений по ЛЗ 9–10
- [ ] В GitHub Actions все проверки зелёные
- [ ] Убедиться, что секреты, `db.sqlite3`, `media/`, `.env` не попали в git
- [ ] Создать резервную копию БД и проверить восстановление
- [ ] `python manage.py migrate`, `python manage.py check`, `python manage.py test`
- [ ] Проверить вход, CRM, финансы, Agile, новые проекты, задачи и отчёты
- [ ] Создать git tag `v2.10` и зафиксировать commit SHA
- [ ] Записать время релиза, ссылку на deployment и ответственного
- [ ] При сбое зарегистрировать инцидент и время восстановления

## Rollback
1. Остановить приложение. 2. Сохранить журналы и состояние БД. 3. Вернуть предыдущий проверенный git tag. 4. Восстановить соответствующий backup БД (обратные миграции необязательно безопасны). 5. Запустить проверки. 6. Записать время восстановления.

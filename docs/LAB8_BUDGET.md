# SmartCRM — бюджет и FinOps: инструкция к расчётной модели

Откройте `docs/lab8_budget.xlsx` и замените **демонстрационные предположения** своими значениями. Модель содержит 12-месячный бюджет, себестоимость на активного пользователя в месяц, точку безубыточности и сравнение размещения за 36 месяцев.

Формулы: `итого = SUM(месячные расходы)`; `стоимость/пользователь/месяц = месячные затраты / число активных пользователей`; `точка безубыточности (пользователи) = ROUNDUP(фиксированные затраты / (цена подписки − переменные затраты на пользователя), 0)` при положительной марже.

Три варианта: публичное облако, собственное оборудование, арендованный сервер с открытым стеком. Цены в файле — условные примеры, **не коммерческие предложения**. Для защиты заполните по актуальным официальным калькуляторам с URL и датой проверки. Никаких покупок или банковской карты не требуется.

# OCTAX 1.6 — демонстрационные данные

Команды работают только с существующим пользователем, например `Galekee`. Используйте Python из виртуального окружения:

```powershell
.\.venv\Scripts\python.exe manage.py seed_demo --user Galekee --batch showcase --companies 15 --clients 50 --leads 30 --deals 35 --tasks 25
.\.venv\Scripts\python.exe manage.py clear_demo --user Galekee --batch showcase
.\.venv\Scripts\python.exe manage.py clear_demo --user Galekee --batch showcase --confirm
```

Первая команда создаёт данные; вторая показывает количество удаляемых записей, ничего не удаляя; третья подтверждает очистку. Повторное создание той же партии блокируется. Для другой партии укажите другой `--batch`.

Демо-записи помечены служебным маркером в полях моделей. Не удаляйте эти маркеры вручную: тогда записи нельзя будет безопасно найти для очистки. Команда очистки отказывается удалять связанные с реальными данными записи. Используйте только для локальной разработки и тестирования. Перед запуском сделайте резервную копию `db.sqlite3`.

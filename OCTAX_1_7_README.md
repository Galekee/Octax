# OCTAX 1.7 — регистрация и QA, вариант №1

Добавлено обязательное поле «Дата рождения» при регистрации. Возраст на дату регистрации должен быть от 18 до 65 лет включительно. Дата рождения сохраняется в заявке на регистрацию. Существующие заявки сохраняются (поле в миграции допускает NULL для старых записей).

## Установка в существующий OCTAX
Сохраните `.env`, `.git`, `.venv` и `db.sqlite3` при замене кода. Затем:

```powershell
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py test crm.test_age_registration crm.tests
.\.venv\Scripts\python.exe manage.py runserver
```

## Лабораторная №8, вариант №1
Эквивалентные классы: меньше 18 — отказ; от 18 до 65 — разрешено; больше 65 — отказ; пустое/неправильное значение — отказ.
Границы: 17, 18, 19, 64, 65, 66. Дополнительно проверяется дата, когда 18-летие наступит завтра.
Тесты реализованы средствами Django. Для строгого требования NUnit требуется отдельный проект C#/.NET; он здесь не заменён Python-тестами.

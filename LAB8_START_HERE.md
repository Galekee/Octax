# SmartCRM — Лабораторная №8 · улучшенная версия

## Что изменено

- «Финансы · ЛЗ 8»: три KPI-карточки (план, факт, остаток), визуальный график 12 месяцев, детализация по месяцам, список статей расходов и CSV-экспорт.
- «SLA и качество»: отдельная страница для трёх сценариев с SLO/SLA и расчётом error budget по заданному количеству корректных запросов.
- Unit economics: средняя плановая стоимость обслуживания одного активного пользователя в месяц с изменяемым предположением о количестве пользователей.
- Документы SoW, SLA/SLO и Excel-модель доступны сотруднику в интерфейсе для скачивания.
- Совместимость с существующим светлым/тёмным режимом SmartCRM; адаптация для узких экранов.

## Установка в Windows / PowerShell

1. Распакуйте ZIP, откройте папку `smart-crm-system` в VS Code.
2. В терминале PowerShell выполните:

   ```powershell
   python -m pip install -r requirements.txt
   python manage.py migrate
   python manage.py check
   python manage.py runserver
   ```

3. Откройте `http://127.0.0.1:8000/` и войдите как сотрудник. При отсутствии учётной записи создайте её через регистрацию или `python manage.py createsuperuser`.
4. Откройте слева «Финансы · ЛЗ 8», создайте несколько статей бюджета для текущего года. Затем перейдите в «SLA и качество».
5. Дополнительно можно проверить тесты: `python manage.py test finance`.

## Особенности

- Это учебный проект. Данные по бюджету вводит пользователь; пустая база показывает нули, а не искусственно придуманные результаты.
- SLO и SLA — **проектные цели** по трем сценариям; активного сбора логов или реального мониторинга они не подразумевают.
- Число пользователей на финансовой панели — **гипотеза пользователя**; это не количество уникальных пользователей в БД.
- Подробная точка безубыточности и трёхлетнее сравнение размещения — в `docs/lab8_budget.xlsx`. Цены в таблице — учебные предположения; для защиты подставьте официальные тарифы с источниками.
- Вся новая финансовая информация изолирована по владельцу; клиентский портал не имеет доступа к этим страницам и файлам.
- ZIP намеренно не включает пароли, `.env`, локальную базу SQLite и виртуальные окружения.

## Что показать преподавателю

1. Добавление расхода → обновление KPI и графика → редактирование / удаление.
2. Изменение года и числа пользователей → изменение расчетов.
3. SLA: три сценария, установленные SLO, error budget (например, 50 неуспешных из 10 000 при SLO 99,5%).
4. Скачать SoW, SLA/SLO, Excel модель из интерфейса.
5. Открыть Excel-модель: 12 месяцев, стоимость / пользователь, точка безубыточности, три варианта инфраструктуры.
